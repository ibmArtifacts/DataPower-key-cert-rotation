# DataPower-key-cert-rotation
This is a script that uploads new key/certs to the gateway and updates the key/cert objects to use the newly updated key/cert crypto files.

NOTE: This does not support containerized DataPower yet.

### What is it doing: rotate_dp_crypto.sh
1. Takes new key and cert crypto files either in the same directory the script is being run from, or the path of the new key/cert, appends the current date and time to the name of the key/cert, and uploads them to the cert:/// directory of the chosen application domain file management system. -- This does not impact the current service yet.
2. Then updates the key and cert objects to use the new key and cert files. -- impacts the service since new key and certs are set now.
3. The script generates a .last_rotation file to keep track of what was changed, therefore if a rollback is required, the --rollback attribute can be used.


### Usage: rotate_dp_crypto.sh
1. Place the new key and cert crypto files in the directory you will be running the [rotate_dp_crypto.sh](https://github.com/ibmArtifacts/DataPower-key-cert-rotation/blob/main/rotate_dp_crypto.sh) script in.
2. Run the script.
3. It will prompt the following inputs:
   - The dp url.
   - The REST management port.
   - The application domain of where the key/cert being used in.
   - Username
   - Password
   - Choose which key and cert objects that will be updated to use the new key/cert crypto files -- script will get a list of the objects for you to choose.

### Usage: rotate_dp_crypto.sh --rollback
For any reason that a rollback is required, please issue the ./rotate_dp_crypto.sh --rollback
NOTE: The .last_rotation file (generated by the script) must exist, otherwise the script will not know how to roll back.

```
$ ./rotate_dp_crypto.sh --rollback
Rollback target: idg:5554 domain 'apic'
Username: admin
Password:
  Crypto Key         'test-key'  -> cert:///private.key.pem   (currently cert:///dp_crypto-privkey_20261030002407.pem)
  Crypto Certificate 'test-cert' -> cert:///public.cert.pem   (currently cert:///dp_crypto-sscert_20261030002407.pem)
Roll back to the previous files? Type 'yes' to continue [no]: yes
[+] CryptoKey 'test-key' -> cert:///private.key.pem
[+] CryptoCertificate 'test-cert' -> cert:///public.cert.pem
[+] Configuration saved.
[+] Rollback complete.
```
